# Student-Grade-Managment-System
Created a student grade managment system for my DBMS project which includes a functional database with marks ,email ,class, section and phone number  linked that with a python code to display edit and update database 

## Files

| File | Purpose |
|------|---------|
| `student_db.sql` | Run in MySQL Workbench to create database + sample data |
| `db_config.py` | Edit your MySQL credentials here |
| `main.py` | Run this in VS Code terminal — the full CLI app |
